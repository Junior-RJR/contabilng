# Contábil NG — site

Site institucional da Contábil NG em **React (JSX) + Vite**, com animações em **Framer Motion**.

## Rodando

```bash
npm install
npm run dev      # desenvolvimento
npm run build    # gera /dist para publicar
```

## Onde editar

- `src/data/content.js` — textos, telefone/WhatsApp, e-mail, serviços, depoimentos e imagens.
- `src/components/` — uma seção por arquivo (Hero, Services, Testimonials, Contact…).
- `src/index.css` — cores (variáveis em `:root`) e estilos.

As imagens atuais são do Unsplash; para usar as oficiais, coloque os arquivos em `public/` e troque os caminhos em `content.js`.
